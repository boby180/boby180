# Arabic Cards – כרטיסיות לערבית מדוברת עם הקראה

תוכנה ללימוד ערבית פלסטינית מדוברת, למחשב Windows: כרטיסיות עם חזרה מרווחת,
הקראה בקולות לבנטיניים וייבוא חפיסות Anki.

## התקנה והפעלה (Windows 11)

1. מתקינים Python 3.13 מ-python.org (בהתקנה מסמנים "Add python.exe to PATH").
2. לוחצים פעמיים על `ArabicCards.bat`. בפעם הראשונה הוא מתקין את הספריות, ואז נפתח החלון.

הפעלה ידנית:

```bat
cd arabic_cards
pip install -r requirements.txt
python main.py
```

## שימוש ראשון

1. מורידים את החפיסה מ-https://ankiweb.net/shared/info/613500521 (כפתור Download).
2. בלשונית **כרטיסים** לוחצים על "ייבוא חפיסת Anki…" ובוחרים את קובץ ה-`.apkg`.
3. בלשונית **הגדרות** משווים בין הקולות על משפט לדוגמה, בוחרים קול ושומרים.
4. בלשונית **חזרה** מתחילים ללמוד.

## הלשוניות

**חזרה.** הכרטיס מוצג ומושמע. מנסים להיזכר, מציגים את התשובה ונותנים ציון.
הציון קובע מתי הכרטיס יחזור, והמרווח כתוב על כל כפתור. כרטיס שקיבל "שוב" חוזר בסוף אותו סבב.

| מקש | פעולה |
|---|---|
| רווח / Enter | הצגת התשובה. כשהיא כבר מוצגת: "טוב" |
| 1 / 2 / 3 / 4 | שוב / קשה / טוב / קל |
| R | השמע שוב |
| E | עריכת הכרטיס |

**כרטיסים.** חיפוש, ייבוא חפיסה, כרטיס חדש, עריכה (גם בלחיצה כפולה), מחיקה והשמעה.

**הגדרות.** קול, קצב דיבור, מספר הכרטיסים החדשים ביום, כיוון הכרטיס
(ערבית בחזית או עברית בחזית) והשמעה אוטומטית. ההגדרות נשמרות ב-`config.json`.

## הגייה נכונה

- לכל כרטיס יש שדה "טקסט להקראה" (`tts_text`). אם הוא מלא, זה הטקסט שנשלח להקראה במקום
  הכתיב הספרותי. כך אפשר לכתוב "شو" במקום "ماذا", או "هون" במקום "هنا".
  בחלון העריכה אפשר לשמוע את התוצאה לפני השמירה.
- הקולות הזמינים הם של ירדן, לבנון וסוריה. הם הכי קרובים לערבית פלסטינית.
- אם לכרטיס יש הקלטה אמיתית מהחפיסה, היא מנוגנת במקום ההקראה.
- ההקראה דורשת חיבור לאינטרנט בפעם הראשונה לכל מילה. אחר כך הקובץ נשמר ב-`data/audio_cache`.

## כלי שורת הפקודה

```bat
python main.py import "Speaking_Arabic_Palestinian.apkg"
python main.py list
python main.py say 1
python main.py voices "شو اسمك"
python main.py review
```

## מבנה

| קובץ | תפקיד |
|---|---|
| `arabic_cards/models.py` | כרטיס (ערבית, תעתיק, עברית, `tts_text`) ומצב חזרה |
| `arabic_cards/storage.py` | מסד SQLite מקומי (`data/cards.db`) |
| `arabic_cards/anki_import.py` | ייבוא ‎.apkg בכל הפורמטים, כולל חילוץ שמע |
| `arabic_cards/srs.py` | חזרה מרווחת (SM-2) |
| `arabic_cards/session.py` | תור הכרטיסים של סבב חזרה אחד, כולל המכסה היומית |
| `arabic_cards/tts/` | מנועי הקראה עם מטמון. כרגע edge-tts |
| `arabic_cards/gui/` | הממשק הגרפי (PySide6): חזרה, כרטיסים, הגדרות, עריכה, ניגון שמע |
| `main.py` | נקודת הכניסה: ממשק גרפי, או פקודות שורת פקודה |

# צופה מדיה

תוכנה לווינדוס לצפייה בתמונות ובסרטונים, בקובץ EXE אחד. לא צריך להתקין כלום.

## הורדה והפעלה (EXE)

1. בדף [Releases](https://github.com/boby180/boby180/releases) של המאגר, פתח את "צופה מדיה" והורד את `MediaViewer-v1.0.0.exe`.
2. לחץ עליו פעמיים. ההפעלה הראשונה לוקחת כמה שניות.
   אם Windows מציג "Windows protected your PC", לחץ "More info" ואז "Run anyway". ההודעה מופיעה כי לתוכנה אין חתימה דיגיטלית בתשלום.
3. פותחים קבצים או תיקייה מהסרגל, או גוררים אותם לחלון.
   אפשר גם ללחוץ על תמונה או סרטון קליק ימני, "Open with" (פתח באמצעות), ולבחור את התוכנה. אז נפתחת כל התיקייה, מהקובץ שבחרת.

התוכנה מנגנת כמעט כל פורמט, כולל AVI, WMV, FLV, MKV ו-MOV, ומציגה JPG, PNG, GIF מונפש, WEBP, BMP, TIFF ו-HEIC של אייפון.

לבנייה של ה-EXE בעצמך: לחיצה כפולה על `build_exe.bat` (צריך Python מותקן).
GitHub בונה את הקובץ לבד בכל שינוי, ובודק שהוא פותח תמונות ומנגן MP4 ו-AVI.

## גרסה לדפדפן

`viewer.html` היא גרסה שנפתחת בדפדפן, עם אותם מקשים. בדפדפן לא מתנגנים AVI, WMV ו-FLV.

## הפעלת הגרסה לדפדפן

1. שמור את `viewer.html` במחשב, למשל ב-`C:\MediaViewer`.
2. לחץ עליו פעמיים. הוא ייפתח ב-Chrome או ב-Edge.
3. לחץ על "פתיחת קבצים" או על "פתיחת תיקייה", או גרור קבצים או תיקייה לחלון.

הקבצים נפתחים רק במחשב שלך ולא נשלחים לשום מקום.

## מה יש בה

* **ניגון רצוף**: כשסרטון נגמר עוברים לבא בתור. כל תמונה מוצגת כמה שניות שבוחרים. אפשר להפעיל סדר אקראי, וחזרה להתחלה בסוף הרשימה.
* **זום בתמונות ובסרטונים**: גלגלת העכבר מגדילה במקום שהעכבר מצביע עליו. גוררים כדי להזיז. לחיצה כפולה מגדילה או מחזירה לגודל רגיל. `1:1` מציג בגודל אמיתי.
* **רשימת קבצים** עם תמונות ממוזערות. אפשר לסנן (תמונות / סרטונים) ולמיין לפי שם, תאריך או גודל.
* מהירות ניגון, עוצמת קול ומסך מלא.

## מקשים

| מקש | פעולה |
|-----|-------|
| `→` / `←` | הקובץ הבא / הקודם |
| רווח | ניגון / השהיה |
| `+` / `-` | הגדלה / הקטנה |
| `0` | חזרה לגודל המסך |
| `1` | גודל אמיתי |
| `Shift` + חצים | הזזת התמונה המוגדלת |
| `Ctrl` + `→` / `←` | 5 שניות קדימה / אחורה |
| `J` / `L` | 10 שניות אחורה / קדימה |
| `↑` / `↓` | עוצמת קול |
| `[` / `]` | האטה / האצה |
| `M` | השתקה |
| `A` / `S` / `R` | ניגון רצוף / אקראי / חזרה |
| `F` | מסך מלא |
| `P` | הצגת / הסתרת הרשימה |
| `?` | כל המקשים |

המקשים עובדים גם כשהמקלדת על עברית.

## פורמטים בגרסה לדפדפן

* תמונות: JPG, PNG, GIF, WEBP, BMP, AVIF, SVG, ICO, ו-HEIC של אייפון. ההמרה של HEIC צריכה אינטרנט.
* סרטונים: MP4, MOV, WEBM, MKV, M4V, OGV, 3GP.
* קבצי AVI, WMV ו-FLV ישנים בדרך כלל לא מתנגנים בדפדפן. התוכנה מסמנת אותם ומדלגת עליהם. כדי לצפות בהם, ממירים אותם ל-MP4, למשל עם HandBrake.

# כיול 4164: עוזר כיול לבקרי SC-AT / SC-NT-4M

תוכנה נפרדת מתוכנת ההפעלה של הבקר (`controller4164`). היא לא מתחברת לבקר: היא קוראת קבצים ששמרת
ב-SC-Shell, מנתחת אותם וממליצה על **שינוי אחד בכל פעם**, לפי מסמך היצרן "SC-AT PIV Control Loop Tuning Guidelines".

## מה התוכנה קוראת

* **PRM** (`File > Upload Controller Parameters` ב-SC-Shell): שורות כמו `XKP[1]=20`, הערות מתחילות ב-`'`.
  מוצגים KP, KI, KD, IS, ER, TL, FF, AG, AF ו-CG לכל ציר. המבנה (PID / PIV) לפי ביט 3 של `CG`.
* **הקלטות:** קובצי **SDV** של SC-Shell / Data Viewer (וקטורים כמו `XPos`, `XPosErr`, `XDesPos`, `XDrvCom`, `XVeldt`, `XVRefdtt`, `XAnlgInp`, ו-`Time` בשניות),
  או קובצי טקסט (CSV / TXT / TSV).

## סוגי בדיקה

| בדיקה | מה מקליטים | מה מקבלים |
|---|---|---|
| **בדיקה מלאה (ברירת מחדל)** | Position Error, Desired Position, Position, Driver Command, Analog Input | קודם חיישן המהירות מול האנקודר (AG), ורק אם הוא תקין: פיגור במהירות קבועה, התייצבות אחרי עצירה, KP / KI |
| השוואת חיישן מהירות (Tacho) לאנקודר | מיקום / מהירות + כניסה אנלוגית | יחס, התאמה, השהיה, ו-AG חדש אם ההפרש מעל 2% |
| צעד מהירות (KP=0) | מהירות רצויה ובפועל | KD ואז KI (לפי המדריך) |
| צעד מיקום קטן | מיקום רצוי ובפועל | KP, KI |
| תנועה רגילה לנקודה | שגיאת מיקום (או רצוי ובפועל) | KP, KI |

בכל הבדיקות, אם מוקלטת גם פקודת הדרייבר, נבדקות רוויה ורעש. בפקודה ברוויה אין המלצה.

ההמלצות מבוססות על כללים ועל ההקלטה בלבד. משנים פרמטר אחד בכל פעם, בודקים במהירות נמוכה, ושומרים בבקר רק כשמרוצים.

## שלוש קבוצות KP/KI/KD

לכל ציר יש שלוש קבוצות: [1] בזמן תנועה, [2] אחרי סוף התנועה עד הכניסה למטרה, [3] בעמידה. בעיה שנמצאה
אחרי העצירה (התייצבות, חיכוך, נדנוד) משנה רק את [2] ו-[3]. בהקלטה עם חיכוך (הציר תקוע והפקודה עולה לאט עד
שהוא משתחרר) ההמלצה היא להעלות KI[2]/KI[3].

## זיכרון כיול

כל ניתוח נשמר אוטומטית (בתיקיית נתוני המשתמש, `history.json`). ההקלטה הבאה של אותו ציר מושווית לקודמת:
מה השתנה ב-PRM, האם ההמלצה הקודמת יושמה, וטבלת מדדים קודם/עכשיו עם השתפר/החמיר. אם השינוי האחרון החמיר,
ההמלצה היא לחזור חצי דרך. הלשונית "היסטוריית כיול" מציגה את כל הרצף, והכפתור שם מתחיל כיול חדש לציר.

## הרצה ובנייה

* מהקוד: `pip install -r requirements.txt` ואז `python run_tuner.py`.
* EXE: `build_exe.bat`, או ב-GitHub Actions ("Tuner 4164 EXE"), שבונה את `Tuner4164-v<גרסה>.exe`.

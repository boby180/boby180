# Ali Tracker – מעקב חבילות AliExpress מתוך Gmail

התוכנה קוראת את המיילים ש-AliExpress שולחת לתיבת ה-Gmail שלך ובונה מהם רשימה של כל החבילות:
מספר מעקב, מה יש בכל חבילה (שם המוצר, וריאציה, כמות ותמונה), איפה החבילה נמצאת עכשיו, ומה צריך לעשות.

## הפעלה

1. מורידים את `AliTracker.exe` מ-
   https://github.com/boby180/boby180/releases/download/ali-tracker-latest/AliTracker.exe
   ושמים אותו בתיקייה משלו, למשל `C:\AliTracker`.
2. לוחצים פעמיים. בפעם הראשונה נפתח חלון ההגדרות.
3. מזינים את כתובת ה-Gmail ו«סיסמה לאפליקציה»:
   - מפעילים «אימות דו-שלבי» בחשבון Google, אם עוד לא מופעל.
   - נכנסים ל-https://myaccount.google.com/apppasswords, יוצרים סיסמה בשם Ali Tracker ומעתיקים את 16 התווים.
4. לוחצים «שמור». התוכנה קוראת את המיילים מ-120 הימים האחרונים ומציגה את החבילות.

התוכנה רק קוראת מיילים מ-aliexpress.com. היא לא מוחקת, לא שולחת ולא מסמנת מיילים כנקראו.
הסיסמה נשמרת מוצפנת (Windows DPAPI) בקובץ `config.json` ליד התוכנה, והנתונים בתיקיית `data`.

## מה רואים

| עמודה | מה זה |
|---|---|
| מספר מעקב | "עדיין אין" אם המוכר עוד לא שלח |
| מה בפנים | המוצרים בחבילה. כל הפרטים והתמונות בחלק התחתון |
| סטטוס | אושר, נשלח, בדרך לישראל, במכס, בישראל, מחכה באיסוף, נמסר, בעיה |
| מה לעשות | בכתום כשצריך לעשות משהו |
| עדכון אחרון | מתי הגיע המייל האחרון |
| ימים מההזמנה | כמה ימים עברו מאז ההזמנה |

כברירת מחדל רואים רק חבילות שעוד לא התקבלו. חבילות שנמסרו או שסימנת «קיבלתי» מופיעות ב«הצג: הכול». חבילה שנמסרה ועוד לא אישרת אותה מופיעה גם ב«דורשות פעולה».

**מתי התוכנה אומרת שצריך לעשות משהו:**
- חבילה מחכה בנקודת איסוף.
- חבילה נמסרה ועוד לא סימנת «קיבלתי ובדקתי».
- המוכר לא שלח 7 ימים מאז שההזמנה אושרה.
- אין עדכון 20 ימים על חבילה שבדרך: לבדוק, ואם צריך לפתוח מחלוקת לפני שתם זמן ההגנה.
- הגיעה הודעה על בעיה במשלוח.
- עבר זמן המשלוח הצפוי (ברירת מחדל: 30 ימים מההזמנה, אפשר לשנות בהגדרות) והחבילה עוד לא הגיעה לישראל: לשלוח הודעה למוכר.

**הודעה למוכר:** הכפתור «✉ הודעה למוכר» מעתיק הודעה מוכנה באנגלית (עם מספר ההזמנה, מספר המעקב וכמה ימים עברו) ופותח את ההזמנה באלי אקספרס. שם לוחצים «Contact seller», מדביקים ושולחים, ואז לוחצים בתוכנה «שלחתי». אחרי 5 ימים בלי שהחבילה הגיעה, התוכנה מציעה לפתוח מחלוקת. התוכנה לא שולחת את ההודעה בעצמה, כי לאלי אקספרס אין דרך מסודרת לזה.

הודעות חדשות ממוכרים מופיעות בפס כתום בראש החלון.
הסנכרון עם Gmail רץ בפתיחה ואחר כך כל 30 דקות (אפשר לשנות בהגדרות).

## פיתוח

```bat
pip install -r requirements.txt
python main.py
python -m pytest -q
```

| קובץ | תפקיד |
|---|---|
| `ali_tracker/mail.py` | משיכת המיילים מ-Gmail ב-IMAP |
| `ali_tracker/parser.py` | פענוח מייל: הזמנה, מספר מעקב, פריטים, סטטוס |
| `ali_tracker/status.py` | שלבי המשלוח ומה לעשות בכל שלב |
| `ali_tracker/store.py` | מסד SQLite מקומי |
| `ali_tracker/gui/` | הממשק הגרפי (PySide6) |
| `ali_tracker/samples.py` | מיילים לדוגמה עם פרטים בדויים, לבדיקות |

הפענוח נבנה לפי המבנה של המיילים של AliExpress בנובמבר 2026. אם הם ישנו את המבנה,
חלק מהפרטים (שם המוצר, תמונה) עלולים לא להופיע, אבל מספר המעקב והסטטוס נלקחים גם מנושא המייל.

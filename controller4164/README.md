# בקר 4164: תוכנת הפעלה

מסך הפעלה ל-4 צירים (J1 עד J4): הזזת צירים, זווית עם 3 ספרות אחרי הנקודה, ביטים לפי קבוע לכל ציר,
לימיטים (ברירת מחדל ‎±200°‎), מילת סטטוס, 16 כניסות, 16 יציאות וקונסולה.

## חיבור לבקר SC-NT-4M

התוכנה מדברת עם הבקר בפרוטוקול ASCII של Control and Robotics Solutions (SC-AT Communication Protocols 3.10,
והמסמך SC-NT-4M Ethernet). הצירים J1 עד J4 הם צירי הבקר X, Y, Z, W.

* **Ethernet:** בוחרים "Ethernet (LAN)", כותבים את ה-IP של הבקר (בדוגמה בתיעוד 192.168.1.254) ופורט 4000 עד 4003.
  למחשב צריך כתובת IP קבועה באותה רשת (מסכה 255.255.255.0).
* **RS-232:** בוחרים את פורט ה-COM ומהירות 38400 או 115200.
* **סימולציה:** בלי בקר. שום דבר לא נשלח.

מה התוכנה שולחת:

| פעולה | פקודות |
|---|---|
| קריאה כל 0.1 שנייה | `_PS` מיקום, `_MS` סטטוס תנועה, `_MO` מנוע, `XIP` / `XOP` כניסות ויציאות, `_SR`, `_EM` |
| סע ליעד / צעד / Home | `_MM=0;_SM=0;_SP=<מהירות>;_AP=<ביטים>;_BG` |
| הזזה רציפה (החזק) | `_MM=1;_SM=0;_SP=±<מהירות>;_BG`, ובעזיבה `_ST` |
| סרבו | `_MO=1` / `_MO=0` לכל ציר |
| עצירת חירום בתוכנה | `_AB` ואחר כך `_MO=0` לכל ציר |
| לימיטים | קריאה `_LL` / `_HL`, כתיבה `_LL=` / `_HL=` (בלי `SV`, כלומר לא נשמר בפלאש) |

הזווית מחושבת כ-`PS / קבוע`, והמהירות נשלחת ב-counts לשנייה: `מהירות מקס' × אחוז × קבוע`.

**עצירת החירום בתוכנה לא מחליפה את לחצן החירום של המכונה.**

מה עוד מוצג (לפי SC-AT Users Manual 3.10):
* **כניסות:** `IP` ביטים 0–15 הם Din1–Din16. ביטים 16–23 הם מתגי הגבול RLS/FLS של X, Y, Z, W, והם מוצגים
  כ-LIM− / LIM+ בכל ציר. ביטים 24–27 הם תקלות דרייבר, וביט 28 הוא כניסת ABORT.
* **יציאות:** 8 יציאות. לחיצה שולחת `XOS,n` (הדלקה) או `XOC,n` (כיבוי), כש-n מ-1 עד 8.
* **סיבת סיום תנועה (`EM`), תקלת מנוע (`MF`) ו"במטרה" (`SR` ביט 0x20)** מוצגים בכל ציר.

מה נוסף לפי SC-AT PC Shell, SC-AT Macro Language ו-Users Manual:
* **סרבו לכל ציר בנפרד:** כפתור ירוק/אדום "Servo ON / Servo OFF" בכל ציר (`_MO=1/0`), כמו ב-Shell המקורי.
  תנועה דורשת רק שהסרבו של אותו ציר יהיה דלוק.
* **שגיאת מיקום** (`_PE`) בכל ציר.
* **מאקרו:** נורה בכל ציר: ירוקה כשהמאקרו של הציר רץ (`XQF[1]`), אדומה כשנעצר בשגיאה (`XQF[3]`).
  הכפתור "עצור מאקרו (QK)" עוצר את כל המאקרו ואת כל התנועות.
* **Home:** אפשר לבחור "מאקרו Home בבקר". אז הכפתור שולח `XQE,#HOME_X` (וכן הלאה לכל ציר).
  את שם התווית אפשר לשנות; `{L}` מוחלף באות הציר. הבקר מקבל עד 6 תווים אחרי `#`.
* **גרסת הבקר** (`XVR`) מוצגת ליד החיבור.
* **שמור בבקר (SV):** שומר את הפרמטרים בפלאש של הבקר, אחרי אישור.
* **שמור הגדרות** שומר גם את ה-IP, הפורט ומצב ה-Home.

מספר הגרסה נמצא ב-`ctrl4164/version.py`. הוא מופיע בכותרת החלון ובשם קובץ ה-EXE.

## הרצה מהקוד (Windows)

לחץ פעמיים על `run.bat`. בפעם הראשונה הוא יוצר `.venv` ומתקין את הספריות (צריך Python מ-python.org).

## בניית EXE

* **במחשב:** לחץ פעמיים על `build_exe.bat`. הקובץ נוצר ב-`dist\Controller4164-v<גרסה>.exe`.
* **ב-GitHub:** כל push שמשנה את התיקייה הזו מריץ את Actions ‏("Controller 4164 EXE"), והקובץ מופיע תחת Artifacts של ההרצה.

## הגדרות

הכפתור "שמור הגדרות" כותב את הלימיטים והקבועים ל-`settings_4164.json` ליד ה-EXE (או בתיקייה הזו כשמריצים מהקוד).
הקובץ נטען אוטומטית בפתיחה.

## בדיקות

pip install -r requirements.txt pytest
python -m pytest -q tests
